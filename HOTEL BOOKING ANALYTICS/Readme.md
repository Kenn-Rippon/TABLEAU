## 📌 Project Overview

This project focuses on analyzing hotel booking data using **Tableau** to identify booking patterns, cancellation trends, customer booking behavior, and hotel performance.

The interactive dashboard provides insights into total bookings, cancellation rates, average daily rates (ADR), booking trends over time, and the geographical distribution of bookings.

The project aims to transform raw hotel booking data into meaningful visualizations that support data-driven decision-making in the hospitality industry.

## 🎯 Project Objectives

- Analyze the total number of hotel bookings.
- Calculate and visualize the hotel booking cancellation rate.
- Examine the average daily rate (ADR).
- Compare booking volumes between City Hotels and Resort Hotels.
- Identify booking trends across different months and years.
- Determine the top 10 countries contributing the highest number of bookings.
- Develop an interactive Tableau dashboard with filtering capabilities.

## 📂 Dataset Information

**Dataset:** Hotel Booking Demand Dataset

**Source:** [Kaggle – Hotel Booking Demand](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)

The dataset contains booking information for two hotel categories:

- City Hotel
- Resort Hotel

It includes information about booking cancellations, arrival dates, customer demographics, booking channels, average daily rates, and other hotel-related attributes.

## 🧹 Data Cleaning and Preparation

Data preparation was performed using Excel Power Query.

The preparation process included:

- Inspecting the dataset for missing values and inconsistent records.
- Checking and assigning appropriate data types.
- Handling missing country information.
- Reviewing missing values in optional identifier fields.
- Filtering booking records based on selected data-quality rules.
- Reviewing unusual ADR values.
- Creating an arrival date field from separate year, month, and day columns.
- Preparing the dataset for analysis in Tableau.

## 🔍 Key Insights

1. **City Hotels receive more bookings:** City Hotels account for approximately two-thirds of the total bookings, exceeding Resort Hotels.

2. **High cancellation rate:** Approximately 37% of hotel bookings were cancelled, indicating that cancellations are an important area for hotel management to monitor.

3. **Portugal contributes the most bookings:** Portugal (PRT) has the highest booking volume among the countries represented in the dataset.

4. **Booking volumes fluctuate over time:** The monthly booking trends show variations across the available years.

5. **Average daily rate:** The dataset's mean ADR is approximately 101.8, providing an overview of booking-level room rates.
